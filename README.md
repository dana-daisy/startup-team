# 🚀 스타트업 팀 시뮬레이터

스타듀밸리 스타일의 픽셀 아트로 구현된 AI 스타트업 팀 시뮬레이션 웹앱입니다.

## ✨ 특징

- **픽셀 아트 스타일**: 스타듀밸리 스타일의 레트로 픽셀 그래픽
- **6명의 AI 에이전트**: 기획자A, 기획자B, 디자이너, 개발자A, 개발자B, 마케터
- **실시간 시뮬레이션**: 에이전트들이 자동으로 업무를 수행하고 회의를 진행
- **PWA 지원**: 모바일 홈 화면에 추가하여 네이티브 앱처럼 사용 가능
- **오프라인 지원**: Service Worker로 오프라인에서도 작동
- **반응형 디자인**: 데스크톱과 모바일 모두 지원
- **다크 모드**: 눈에 편한 다크 테마 기본 적용

## 🎮 게임 기능

### 시각화
- HTML5 Canvas로 구현된 픽셀 아트 오피스 환경
- 각 에이전트마다 다른 색상과 애니메이션
- 걷기/앉기 애니메이션 지원
- 말풍선으로 현재 작업 상태 표시
- 책상, 컴퓨터, 화이트보드, 커피머신 등 오피스 가구 배치

### 에이전트 시스템
- 각 에이전트가 역할에 맞는 업무 랜덤 수행
- 주기적인 팀 회의 시스템
- 실시간 활동 로그
- 프로젝트 진행률 추적
- 에이전트 상태 대시보드

### 상호작용
- 에이전트 클릭으로 상세 정보 확인
- 스페이스바로 게임 일시정지/재개
- 터치 지원으로 모바일에서도 편리한 조작

## 📁 파일 구조

```
startup-team/
├── index.html          # 메인 HTML 파일
├── style.css           # 스타일 및 반응형 디자인
├── app.js              # 메인 게임 로직 및 Canvas 렌더링
├── agents.js           # AI 에이전트 시스템
├── manifest.json       # PWA 매니페스트
├── service-worker.js   # 오프라인 지원 및 캐싱
└── README.md          # 프로젝트 설명서
```

## 🚀 실행 방법

### 로컬 개발
1. 파일들을 웹 서버에서 실행 (file:// 프로토콜로는 Service Worker가 작동하지 않음)
2. Python 간단 서버 사용:
   ```bash
   python -m http.server 8000
   ```
3. 브라우저에서 `http://localhost:8000` 접속

### PWA 설치 (모바일)
1. 웹 브라우저에서 앱 접속
2. 브라우저 메뉴에서 "홈 화면에 추가" 선택
3. 설치 후 홈 화면 아이콘으로 실행

## 🎯 조작법

- **클릭/터치**: 에이전트를 클릭하면 현재 상태 확인
- **스페이스바**: 게임 일시정지/재개
- **반응형**: 모바일에서는 세로 레이아웃으로 자동 전환

## 🛠 기술 스택

- **순수 JavaScript**: 외부 라이브러리 없이 바닐라 JS로 구현
- **HTML5 Canvas**: 픽셀 아트 렌더링
- **CSS3**: 다크 테마 및 반응형 디자인
- **PWA**: Progressive Web App 표준 준수
- **Service Worker**: 오프라인 지원 및 캐싱
- **Press Start 2P**: Google Fonts의 레트로 게임 폰트

## 📱 모바일 최적화

- **터치 이벤트**: 모바일 터치 지원
- **반응형 레이아웃**: 화면 크기에 따라 UI 자동 조정
- **PWA**: 홈 화면 설치 및 네이티브 앱 경험
- **성능**: 60fps 타겟 최적화
- **배터리**: 효율적인 애니메이션 및 업데이트

## 🎨 디자인 컨셉

### 색상 팔레트
- 배경: `#0f0f23` (다크 네이비)
- UI 요소: `#1a1a2e` (미드 그레이)
- 액센트: `#00ff88` (네온 그린)
- 텍스트: `#ffffff` (화이트)

### 픽셀 아트
- 32x32 픽셀 스프라이트
- Canvas drawRect()로 픽셀 단위 직접 렌더링
- 크리스프한 픽셀 렌더링 설정
- 레트로 게임 스타일 애니메이션

## 🔧 커스터마이징

### 에이전트 추가
`agents.js`의 `AgentManager.initializeAgents()`에서 새 에이전트 설정:
```javascript
{
    name: '새에이전트',
    role: '새역할',
    color: { hair: '#색상', shirt: '#색상', pants: '#색상' },
    x: 100, y: 100
}
```

### 업무 내용 수정
`Agent.getTasksByRole()`에서 역할별 업무 목록 편집 가능

### UI 테마 변경
`style.css`에서 색상 변수 수정으로 테마 커스터마이징
